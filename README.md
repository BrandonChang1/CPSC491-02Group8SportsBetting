# Sports Betting App

Project repository for the CPSC 491 sports-betting application.

## Layout

- `frontend/` — client application
- `backend/` — server application and API tests
- `ml/` — model assets, training code, and ML tests
- `data/` — data collection, processing, and samples
- `database/` — schema and migrations
- `tests/integration/` — cross-service tests
- `docs/` — project documentation
